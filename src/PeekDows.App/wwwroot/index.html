General

Core behavior of PeekDows. Changes apply when you press Save.

Guide de démarrage
Enable PeekDows
Master switch. When off, nothing is ever moved.
Auto arrange
Continuously monitor windows and arrange them as they open or close.
Animate window transitions
150 ms ease-out tween when windows move into their slots.
Directional focus
Hold Ctrl+Win and flick the mouse toward a screen zone to focus that slot. Any other key cancels.
Start with Windows
Create a shortcut in the Startup folder.
Arrange on startup
Run one arrange as soon as PeekDows launches.
Show tray notifications
Occasional tray balloon messages (off by default).
Pause arranging
Pause immediately without changing saved settings.

Layout
